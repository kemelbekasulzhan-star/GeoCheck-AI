# Открытые материалы КМГ

Проверка 18 ноября 2026 года. Запрос пользователя — использовать данные, опубликованные на сайтах КазМунайГаза, для обучения анализа скважин.

## Что удалось установить

Годовой отчёт содержит сведения о геологоразведочных проектах и результатах бурения. В проверенном разделе обучающая таблица с рядами каротажных измерений по глубине не найдена. [Официальный отчёт 2025](https://ar2025.kmg.kz/ru/strategic-report/operating-review/exploration).

Официальная статья о Восточном Урихтау описывает скважинный фонд и инфраструктуру. Она может служить справочным материалом для карточки месторождения. Для обучения текущей модели требуются сами измерения GR, RHOB, NPHI, DT или RES по глубине. [Материал КМГ](https://kmg.kz/ru/press-center/articles/skvazh-urikhtau/).

Поиском по kmge.kz обнаружен технический сборник с описаниями и оценками качества ГИС. Полный PDF и возможность извлечения из него измерений не проверялись. В приложении он обозначен как кандидат для исследования. [Технический сборник](https://www.kmge.kz/wp-content/uploads/2022/04/Свод-сборника-с-разделами-22072021.pdf).

Поиск по kmg.kz с ограничениями filetype:las и filetype:csv не дал подтверждённого набора каротажа. Это ограниченный результат поиска, доступность всех публикаций компании не установлена. Для включения конкретного набора нужны файл с числовыми рядами, описание каналов и единиц, идентификаторы скважин, происхождение и условия использования.

## Применение в GeoCheck

В каталоге данных можно записать URL источника при загрузке LAS/CSV. Источник переносится в паспорт обучающей выборки. Синтетические данные имеют явную метку. В этой версии страницы КМГ открываются по ссылкам, их тексты не использованы как каротажные измерения. Модель обучена для демонстрации на воспроизводимых синтетических скважинах.

Для входа в обучение через API сначала импортируйте скважины, затем передайте их идентификаторы в /api/models/train. Обучение допускает только совпадающие каналы с указанными одинаковыми единицами. Разные единицы необходимо предварительно привести по документации измерений.
