# Windows-пакет и локальный помощник

Дата: 20.11.2026. Пользователь выбрал готовый ZIP для Windows без отдельной установки Python/Node.js и попросил публикацию на GitHub.

## Как устроен запуск

Исходники React требуют Node.js только при сборке. FastAPI и алгоритмы выполняются Python-сервером. В Windows-пакете интерпретатор и зависимости включены PyInstaller, а React уже собран. Пользователь распаковывает папку и запускает EXE. Это по-прежнему локальное браузерное приложение: EXE запускает сервер и открывает браузер, а не отправляет файлы в облако.

Сборка разработчиком: установить Python-зависимости, `pip install pyinstaller==6.22.3`, `npm ci --prefix frontend`, `npm run build --prefix frontend`, затем `powershell -File scripts/build-windows.ps1`. Скрипт позволяет указать `-Python`, `-Output`, `-Work`. В архив должна войти вся папка GeoCheck. Базы данных не включать. Установщик исходников — отдельный путь, не обязательный этап для готового ZIP.

## Модель

- Карточка: https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507 (Apache 2.0).
- GGUF: https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF/tree/a06e946bb6b655725eafa393f4a9745d460374c9 .
- SHA-256 модели: `3605803b982cb64aead44f6c1b2ae36e3acdb41d8e46c8a94c6533bc4c67e597`.
- llama.cpp: https://github.com/ggml-org/llama.cpp/releases/tag/b12321 (MIT), Windows Vulkan-сборка используется в CPU-режиме для переносимости.
- SHA-256 runtime ZIP: `de3d073fa71d88f067be27700b7110cc0679d1643390348c9e83ee8d0a6f7ba2`.

Первичная загрузка запускается явной кнопкой. Интернет используется для скачивания весов/runtime. Запросы анализа направляются только на локальный llama-server (127.0.0.1:3134), без API-ключей и облачных запросов. Для диагностики разработчик может задать `GEOCHECK_AI_DIR` и `GEOCHECK_AI_PORT`. Модель не обучается на пользовательском вопросе и не дообучена на каротаже КМГ. Промпт и ограниченный JSON-контекст помогают привязать ответ к анализу, но не гарантируют фактическую безошибочность.

API: GET `/api/assistant/status`, POST `/api/assistant/install`, POST `/api/assistant/ask` с analysis_id, необязательным finding_index и question. Контекст выбирается сервером из сохранённых измерений. Параллельный запрос во время ответа получает 409. Отсутствующая модель не подменяется шаблонным ответом. Ошибки/прогресс видны в UI. Исходные данные и экспертные отметки не меняются.

## Границы проверки

Установщик проверяется в чистой папке на этом компьютере. EXE дополнительно проверяется с PATH без Python/Node и отдельной рабочей базой. Это не проверка второго физического компьютера. Тесты контекста с подменой транспорта проверяют интеграцию, а живой ответ Qwen проверяется отдельно; их нельзя смешивать с оценкой геологической достоверности модели. Производительность зависит от CPU, свободной памяти и длины контекста.
