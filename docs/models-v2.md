# Обучение моделей в GeoCheck 2.0

## Воспроизводимый эксперимент

Кнопка восстановления демо создаёт две чистые скважины с seed 117 и 118. GeoLab-01 имеет seed 2026 и пять искусственных интервалов. Выберите обе чистые скважины для обучения и GeoLab-01 для проверки. Настройки по умолчанию — 150 деревьев, contamination 0,025 и seed леса 42. Признаки GR, RHOB, NPHI, DT, RES.

Проверено на 1602 обучающих строках и 801 проверочной. Получено 43 отмеченные строки. По искусственной разметке TP 19, FP 24, FN 30, TN 728. Precision 0,442, recall 0,388, F1 0,413. Результат относится к Isolation Forest отдельно. Пропуски и физические нарушения дополнительно проверяются правилами в основном анализе.

Эта оценка ограничена синтетическими данными из одного генератора. Модель нуждается в валидации на реальном каротаже. Порог и настройки нельзя подбирать по финальной проверочной выборке. При подборе используйте дополнительную валидационную группу и сохраняйте независимый финальный тест.

## Хранение и совместимость

В новой таблице trained_models сохраняются полный pipeline joblib, входные каналы и единицы, параметры, версии sklearn, seed, паспорта скважин и хеши измерений. Артефакт создаёт сервер, импорт внешних pickle/joblib отсутствует. После изменения версии sklearn требуется новое обучение.

В процессе обучения из данных исключаются полностью пустые строки. Каждый выбранный канал должен содержать измерения на обучении. Импутация медианой и StandardScaler обучаются исключительно на обучающей выборке. Пустые строки проверочной скважины исключаются из метрик с указанием количества. Precision/recall/F1 вычисляются только при известной искусственной разметке. Для пользовательского файла без разметки сохраняются объём проверки и число отмеченных строк.

Проверяется раздельность ID, названий скважин и хешей измерений между выборками. Пользователь должен сохранять одинаковое название для разных файлов одной физической скважины. Автоматически установить идентичность произвольно переименованных файлов невозможно.

При применении сохранённой модели используются её деревья и параметры подготовки. Порядок признаков и единицы должны совпадать. Параметры деревьев и порога в отчёте берутся из модели. При анализе обучающей скважины результат является внутривыборочной проверкой, её показатели нельзя представлять как качество на новых скважинах.

## Экспертная проверка

Подтверждение, отклонение и комментарий хранятся по ID анализа и индексу интервала в новой таблице reviews. Отметка автоматически не переносится в другой запуск. JSON-отчёт включает решения и комментарии. Изменение решения и удаление файла сериализуются транзакциями SQLite. Исходный файл хранится как ранее.

Решения эксперта пока не используются для обучения классификатора. Для такого обучения нужны размеченные ошибки и нормальные интервалы с согласованными критериями, а также раздельные обучающие и проверочные скважины.
